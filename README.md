# 👶 השמות של ישראל | ShemotIL

> הפלטפורמה המקיפה והאינטראקטיבית בישראל לגילוי, ניתוח ובחירת שמות לתינוקות – מבוססת נתוני למ"ס היסטוריים ומשחק החלקות זוגי בזמן אמת.

🔗 **לאתר החי:** [shemotil.co.il](https://shemotil.co.il)

---

## ✨ פיצ'רים מרכזיים

* 📊 **תיק מקיף לכל שם (~5,700 שמות):** ניתוח שכיחות היסטורי (1949–היום), שנת שיא, התפלגות מגדרית, משמעות וגימטריה.
* 💕 **NameMatch – משחק זוגי בזמן אמת:** החלקת שמות בסגנון Tinder בין בני זוג בסנכרון מלא על גבי Supabase Realtime, עם התראת "Match" מיידית כששניכם אוהבים את אותו השם.
* 🚀 **עמודי אוספים מותאמים ל-SEO:** דפי נחיתה ייעודיים לשאילתות חיפוש מובילות – שמות לבנים, שמות לבנות, שמות יוניסקס והשמות הנפוצים בישראל.
* ⚡ **ארכיטקטורה מהירה ונקייה:** דפי מידע ואוספים סטטיים לחלוטין לטעינה מיידית ולסריקה אופטימלית במנועי חיפוש, לצד מנוע Realtime מבודד למשחק.
* 🔍 **מנוע חיפוש וסינון:** חיפוש מהיר לפי אותיות, מגדר, פופולריות ומאפיינים מיוחדים.

## 🛠️ ארכיטקטורה וטכנולוגיות

| שכבה | טכנולוגיה | תפקיד |
| :--- | :--- | :--- |
| **Hosting & Edge** | Vercel | פריסת אתר סטטי עם Edge Caching מהיר במיוחד |
| **Realtime Engine** | Supabase | ניהול חדרי NameMatch, סנכרון WebSockets ומדיניות RLS |
| **Static Site Generator** | Python & Node.js | בניית 5,700+ עמודי HTML סטטיים, יצירת sitemap.xml ו-robots.txt |
| **Analytics & Monetization** | Vercel Analytics & Google AdSense | מעקב ביצועי אתר ואינטגרציית מודעות |

---

## 📂 מבנה הפרויקט

* `source/` – קוד המקור, נתוני הלמ"ס הגולמיים וכלי הגנרציה (`build_site.py`).
* `src/` – האתר הסטטי המוכן לפריסה (עמודי שמות, אוספים ואינדקס א–ת).
* `scripts/finalize.mjs` – שלב ה-Build ב-Vercel: עדכון כתובות קנוניות, יצירת sitemap.xml והזרקת נכסים.
* `supabase/migrations/` – סכמות נתונים, פונקציות RPC ומדיניות אבטחה (RLS) עבור חדר המשחק.
